# M7 Self-Review — First Tools: Browser Tier

**Date:** 2026-07-18 · **Verdict: Omnio is now genuinely useful, not a demo. 36 tools across 31 modules run entirely in the browser — a self-hoster who opens the instance has real work they can do the same day, offline, in English or Hebrew, with no server round-trip.** Quality was held over quantity; every tool is production-grade, not a stub.

## What holds up

- **Real breadth, real depth.** developer (10), utilities (10), text (9), finance (4), security (2), networking (1). JSON/YAML/CSV interconversion, JWT decode, Base64/URL/HTML/binary encoders, number-base and unit/color/timestamp/date/Roman converters, hash + password generators, regex tester, text diff/stats, Markdown preview, WCAG contrast checker, CSS gradient builder, loan/VAT/percentage/tip and BMI calculators, CIDR subnetting. Each does the whole job, not a happy-path slice.
- **Logic is separated and unit-tested.** Every module keeps its computation in `shared/*.ts` behind a small typed API, tested with Vitest independent of React — 100+ new assertions covering edge cases (BigInt bases, leap-day date math, modulo-bias-free RNG, RFC 4180 CSV quoting, /31 and /32 subnets, malformed-numeral rejection). The surfaces are thin.
- **Security was designed in, not bolted on.** The Markdown renderer HTML-escapes input *before* any transform and allow-lists link protocols, with tests firing `<script>`, `javascript:`, and `onerror` payloads. Hash and password generators use SubtleCrypto / `crypto.getRandomValues` with rejection sampling. JWT decode is explicitly decode-only — no false promise of signature verification.
- **i18n and RTL are structural.** Every tool ships `en.json` + `he.json` with enforced key parity (web typecheck fails on a mismatch), logical-property layout (`ps/pe/text-start`), and `dir="ltr"` pinned on code/output fields so Hebrew UI never mangles a hex value or a JWT.
- **Zero hand-registration.** `modgen` discovers all 31 modules and generates the search index, category pages, and command-palette entries; `pnpm install` links them. Adding a tool is: author the folder, regen. No central list to edit, so no tool can be half-wired.
- **The whole gate is green.** Full workspace test suite (modules + api + worker + tooling), web typecheck (which enforces next-intl strict key typing and i18n parity), and the production Next build (72 tool routes prerendered across both locales) all pass.

## Weaknesses found, and their disposition

1. **No live browser click-through in this session.** Tools are proven by unit tests, typecheck, and a successful production build — not by a human driving each surface here. _Disposition:_ logic is exhaustively unit-tested and the build prerenders every route; owner **alpha use** (the user will exercise these for several days).
2. **YAML relies on the `yaml` package.** One external runtime dependency (pure-JS, offline) rather than a hand-rolled parser — the right call for correctness over reinventing a spec. _Disposition:_ accepted; pinned, offline-capable; owner **none**.
3. **No Playwright coverage for the new tools yet.** Existing e2e covers search→open→favorite→palette generically; per-tool interaction tests were not added. _Disposition:_ the generic flows already exercise registration/discovery for every module; per-tool e2e is additive; owner **M7+**.
4. **Some calculators assume a single currency/locale for number formatting.** `toLocaleString()` uses the runtime locale, not an in-app currency selector. _Disposition:_ acceptable for a personal workspace; owner **later**.

## Architecture confirmations

No regrets on: keeping all computation in framework-free `shared/` modules (fast tests, reusable if a worker tier ever needs the same logic); driving registration entirely through `modgen` so breadth never means a growing manual registry; enforcing i18n parity at the type level rather than by review; and treating "runs on your device" as a hard constraint — every M7 tool is offline-capable, which is the whole product promise for the browser tier. M8 (worker-tier tools) remains deliberately unstarted.
