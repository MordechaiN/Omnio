# Omnio v0.8.0-alpha

**Omnio starts paying attention — 2026-07-25**

Until now Omnio kept your files without ever understanding them. This release
adds the first thing that reads a file for what it plainly is — and, just as
importantly, tells you what led it to that conclusion.

> **Alpha.** Interfaces and data shapes may change between pre-releases. Personal
> mode has no authentication by design — do not expose an instance holding data
> you are unwilling to make public.

## 🚀 New

### Omnio notices — and explains itself

Drop in a scanned contract. Omnio says:

> **Looks like a scan** — no selectable text — this looks like a scan
> → *OCR — Make Searchable*

It also recognises screen captures, photos taken on a camera or phone, files you
already have an identical copy of, images far larger than any screen will show,
and files big enough to be awkward to send.

The reason is not a tooltip or a detail view — it *is* the sentence. A
suggestion you cannot account for reads as guessing, and a single wrong guess
costs more trust than ten useful observations earn.

**It stays quiet when it does not know.** A document Omnio has not looked at yet
gets no opinion. A blank page is not called a scan just because it has no text
on it. Silence is a better answer than a confident mistake.

Everything is worked out on your own device, from names, sizes, dimensions and
whether a document carries a text layer. There is no model and nothing leaves
your machine.

### Home picks up where you left off

The work you were in the middle of is now the first thing on the page, each file
carrying whatever Omnio noticed about it instead of a timestamp. Before you have
done anything it stays out of the way entirely.

## Verified

193 build, lint, typecheck and unit tasks; 19 unit tests over the reasoning
itself; and 71 browser tests, six of them covering what Omnio says about real
documents — including proof that a text document and an empty page both stay
quiet.

## ⚠️ Known limitations

- Recognition is based on plain evidence — how a file is named, how large it is,
  whether a document carries text. It will not identify what a document is
  *about*.
- A file is inspected the first time you look at it, so an observation can appear
  a moment after the file does.
