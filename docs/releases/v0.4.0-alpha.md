# Omnio v0.4.0-alpha

**Handling pages like paper — 2026-07-24**

This release finishes Omnio's PDF experience. Rearranging pages, signing a
document, and building a table of contents were the last everyday jobs that
still sent people to another app.

> **Alpha.** Interfaces and data shapes may change between pre-releases. Personal
> mode has no authentication by design — do not expose an instance holding data
> you are unwilling to make public.

## Organize Pages

Every page is shown as a thumbnail you can drag into a new position. Click to
select, Shift-click for a run, Ctrl-click to add to the selection, or press
Ctrl+A for the lot. With a selection you can rotate, duplicate, delete, or
insert a blank page, and Ctrl+Z undoes up to fifty steps.

Nothing is written until you save: the grid edits a list of page slots, so every
operation is instant no matter how long the document is, and the whole session
stays undoable. Rotation is added to whatever angle a page already had, so a
page that arrived sideways turns from where you see it, not from where the file
thinks it is. An inserted blank takes the document's own page size rather than
defaulting to A4.

This replaces the old page-reorder screen, which was a plain text list with no
preview.

## Sign a document

Draw a signature, type your name in a handwriting face, or upload an image of a
signature you already use. Place it by dragging a box on the page; it is fitted
inside that box without being stretched, because a distorted signature looks
forged.

**What this is not:** a picture of a signature, not a cryptographic one. It
carries no certificate and no proof of identity that software can verify. The
interface states this where you sign rather than leaving you to assume. The
groundwork for certificate-based signing is in place for a later release.

## Bookmarks and contents

Read a document's existing bookmarks, add new ones, rename them, nest them
under one another, and reorder them — then save a PDF that opens with a working
contents list. Entries without a title, or pointing outside the document, are
skipped rather than written as broken links, and the screen tells you how many
before you save.

## Fixed

Omnio had been reporting its own version as `0.0.0-dev` with an unknown commit
on every screen that displays it. The release metadata is computed on the host
and passed into the image at build time, but any build that bypassed the release
pipeline silently fell back to placeholder values. The fallbacks are gone: a
build without real metadata now fails with an explanation instead of producing
an image that misdescribes itself.

## Verified

- 66 unit tests across the PDF module, including the page-slot model and the
  outline tree.
- 7 integration tests applying page operations to real generated PDFs.
- 38 browser tests, 9 of them new and covering the page organizer, signing, and
  the bookmark editor end to end.

## Known limitations

- **PDF/A** is not supported. Re-checked against MuPDF 1.28 for this release: it
  cannot emit conformant PDF/A, so this needs a Ghostscript-class engine Omnio
  does not yet carry. A file claiming PDF/A without passing validation would be
  worse than not offering it.
- **PDF to Word/Excel and table extraction** are not supported. Reliable table
  detection is not available in the engines Omnio uses, and a guesser that fails
  quietly is not worth shipping.
- **Office to PDF runs on the server**, not in your browser. That one job sends
  your file to your own Omnio instance; everything else in this release stays on
  your device.
