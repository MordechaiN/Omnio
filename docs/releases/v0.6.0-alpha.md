# Omnio v0.6.0-alpha

**Files, the way a desktop does it — 2026-07-25**

The workspace arrived in the previous release. This one makes working in it feel
like the file manager you already know, rather than a web page that happens to
list files.

> **Alpha.** Interfaces and data shapes may change between pre-releases. Personal
> mode has no authentication by design — do not expose an instance holding data
> you are unwilling to make public.

## 🚀 New

**Views.** Switch between a thumbnail grid and a compact list, and choose small,
medium or large thumbnails. The choice is remembered.

**Right-click anything.** A full menu — open, open with, quick look, rename,
duplicate, pin, tag, add to a collection, delete — with submenus where a choice
is a list. It also opens on a touchscreen long press and with the keyboard menu
key.

**Filters.** Narrow by tag and collection. The button carries a count, so a
filtered workspace can never be mistaken for an empty one.

**Saved searches.** Name a search you return to and bring it back in one click.

**Collections.** Group related files, and create a new group at the moment you
file something into it rather than in a separate step first.

**Duplicate**, without using additional space.

## ✨ Improved

- Moving through a large workspace stays smooth; changing the selection no
  longer redraws every file on screen.
- The details panel gained a copy button for a file's details, and now draws
  where a file came from as a chain you can follow rather than a flat list.
- Rename can be started from the right-click menu.
- The keyboard shortcuts card lists the file shortcuts, so they can be found.

## Verified

- 193 build, lint, typecheck and unit tasks.
- 59 browser tests, 21 of them covering Files end to end: views surviving a
  reload, tag filtering, saved searches round-tripping, right-click actions,
  duplication, rename from the menu, and a tool's output returning to the
  workspace.

## ⚠️ Known limitations

- Files are kept on this device, in this browser. Nothing is synced, and
  clearing browser data clears them — an exported copy remains the real backup.
- Private browsing generally forbids storing files. Omnio detects this and says
  so; tools keep working, files simply are not remembered.
- There are still no folders. Tags, collections and saved searches cover the
  same ground.
