# Omnio v0.7.0-alpha

**Omnio starts remembering how you work — 2026-07-25**

Every tool in Omnio has been something you operate. This release adds the first
thing that watches how you operate them, and offers to do it for you.

> **Alpha.** Interfaces and data shapes may change between pre-releases. Personal
> mode has no authentication by design — do not expose an instance holding data
> you are unwilling to make public.

## 🚀 New

### Chains

Rotate a scan, then compress it. Omnio notices. Open a similar file later and it
offers: *you did this before* — do it again.

Say yes and it runs the sequence, handing the result of each step into the next
by itself. You are never sent to your downloads folder to fetch an intermediate
file and drag it back in.

The part worth stressing: **there is nothing to build.** No canvas, no boxes and
arrows, no configuration screen. Asking someone to assemble a pipeline before
they have a problem is why most automation features go unused. The sequence you
already performed is better evidence of what you want than anything you would
have configured in advance.

Chains are offered by what is left to do. If half the work is already done to a
file, only the remaining steps are offered. Keep one you like and it stays.

### A chain in progress follows you

A strip along the top shows the steps, which one you are on, and how many
remain. Stop at any point; nothing is left half-applied, because each step
produces a real file of its own that stays in your workspace.

### Files remember where they came from

Anything a tool produces is now linked to the file it was made from, so the
details panel can show a document's whole story — what it started as, and every
step between then and now.

## ✨ Improved

- Suggestions no longer lead with tools that need several files when you have
  selected one. "Merge PDFs" cannot do anything with a single document, and
  offering it first was a poor first impression.

## Verified

193 build, lint, typecheck and unit tasks; 25 unit tests over how sequences are
read out of a file's history; and 65 browser tests, four of which drive chains
end to end — noticing a sequence, offering it, carrying a file from one step to
the next, finishing, and stopping partway.

## ⚠️ Known limitations

- A chain runs a step at a time and waits for you at each one. Tools ask for
  their own settings — a rotation angle, a page range — so Omnio walks you
  through rather than guessing what you meant.
- Chains are learned from what you have done on this device. A brand-new
  workspace has nothing to offer until you have done something twice over.
- A chain in progress lasts for the browsing session. A half-finished chain is
  not something to be greeted with tomorrow.
