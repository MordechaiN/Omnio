# Omnio

**Everything. One Workspace.**

A completely self-hosted, privacy-first workspace for opening, viewing, editing, converting, analyzing, and managing virtually every common file format — and the everyday digital tasks around them — from one beautiful interface.

> **Status: architecture phase.** No implementation code yet, by design — Omnio is being built platform-first, and the platform is being designed before it is built.

## Start here

The complete architectural design lives in [`docs/architecture/`](docs/architecture/README.md):

- What Omnio is and the critical review of its vision
- The three-tier tool execution model (browser-first: most tools never send your files anywhere)
- The module system that lets the tool count grow by orders of magnitude without the core growing at all
- The security model for safely processing untrusted files
- The roadmap to v1.0 and the decisions currently awaiting sign-off

## Principles (the short version)

Privacy-first · self-hosted · Docker-first · offline-friendly · accessible (WCAG AA) · RTL and LTR both native · beautiful by default · simple for beginners, powerful for professionals.
